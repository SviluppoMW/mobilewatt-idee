# mobilewatt-idee

Ogni mattina alle 6:15 (ora di Roma, d'inverno) GitHub Actions legge i feed delle fonti dell'energia
(`notizie.py`), sceglie tre notizie (`idee.py`) e le scrive in `idee.json`. La pagina del piano editoriale
di Mobile Watt le mostra in cima come «Le idee di oggi». Pubblico di proposito: dentro ci sono solo titoli
e link di notizie già pubblicate, nessun segreto e nessun dato personale.
